# 🕵️ AI侦探社 —— 查得到，信得过

> WaytoAGI × 元宝搜索《侦探》赛道参赛作品
> 少点幻觉，多点搜索：给它一个问题，它去全网查清楚，带着证据回来。

## 四条评分点，逐条落地

| 评分点 | 实现 |
|---|---|
| 查得准 | 侦探系统提示词内置四步办案：**立案拆解 → 多轮走访（中英文各查） → 交叉对质 → 结案** |
| 来源点得开 | 结案报告每条结论挂链接；正文下方自动抽取所有链接渲染成**「证物卡」**，点击直达来源 |
| 查不到敢说不知道 | 报告强制包含【未查到】专区；检测到"未查到/查不到"自动亮出**🎖️诚实徽章** |
| 好用/好玩 | 卷宗纸面 + 侦探绿视觉、打字机办案过程、"证物 N"编号卡片、卷宗柜 |

## 三个进阶挑战（都做了）

1. **🧭 深度调查**：先出侦查计划 → 逐方向多轮搜索 → 交叉比对表 → 带证据链的调查报告
2. **📌 持续盯梢**：案件存入本机卷宗柜（localStorage），一键「再次盯梢」，侦探带着上次报告重新走访，输出《变化梳理》
3. **📸 截图查证**：先"认出"截图里在传什么话（用户填写主张）→ 溯源 → 查证 → 属实/存疑/不实/未查到四选一

## 运行（零依赖，无需 npm install）

```bash
# 启动（零依赖）
node server.js

# 打开
# http://localhost:3000
```

**配置密钥（二选一）**：
- 推荐：打开页面后点右上角 **⚙️ 设置**，填入两组档案，保存即生效（自动写入 `.env`，无需重启）；
- 或手动：复制 `.env.example` 为 `.env` 填入。

需要两套密钥（缺一不可，分工不同）：

| 档案 | 用途 | 填什么 |
|---|---|---|
| 🔎 元宝搜索 | 走访取证（调 SearchPro，`Authorization: Bearer` 鉴权） | 元宝搜索 API Key（sk-xxxx） |
| 🧠 侦探大脑 | 基于证据写结案报告（OpenAI 兼容接口） | API 地址 / Key / 模型名（如 codex） |

```
YB_API_KEY=元宝搜索API Key（sk-xxxx）
AI_BASE_URL=https://模型API地址/v1
AI_API_KEY=sk-xxxx
AI_MODEL=模型名
```

> 若你的 API 不是 OpenAI 兼容格式，只需改 `server.js` 中第 4 部分（streamInvestigate 函数）的请求与解析逻辑，前端无需动。

